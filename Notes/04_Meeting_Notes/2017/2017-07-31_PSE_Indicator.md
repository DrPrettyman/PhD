# A function to generate coloured noise


![](../../images/noise_gen_test_acfpseplot.png)
The mean of the ACF and PSE indicators of 20 coloured noise
samples of length 10000 for values of
α in the range 
[0, 3]. 


We construct a function in Matlab which returns "coloured noise", a
noise sample generated by manipulating the fast Fourier transform of a
white noise sample so that the power spectrum will have a different
slope. The function then returns the real part of the inverse
transform.\
The function is constructed so that for input parameter $\alpha$ we get
a noise sample which has a PSE indicator value of $\alpha$. In figure
[1](#noise_gen_test_acfpseplot)
 we see that this result is
achieved. In figure [1](#noise_gen_test_acfpseplot)
 we have generated $20$ coloured
noise samples of length $10000$ for $\alpha$ in the range $[0,3]$
sampled at frequency $0.05$. we have then calculated the PSE and ACF$_1$
indicators for all of the $20$ samples and taken the mean.
